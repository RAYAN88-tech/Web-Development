Function Parameters

What is a Function Parameter?

Think of a parameter as a designated slot or variable inside a function that waits to receive data. When we call the function, we pass actual values (called arguments) into those slots.

The Javascript Code Parameters: a, b
function multiplyNumbers(a, b) {
return a * b;
}
let result = multiplyNumbers(5, 6);
